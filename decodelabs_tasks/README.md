# DecodeLabs - AI/ML Task Projects

A collection of AI and Machine Learning projects built during the DecodeLabs internship program. Each project demonstrates different aspects of AI engineering — from classical ML to deep learning and agentic systems.

## 📁 Projects

### 1. [Object-Detection](./Object-Detection/)
Real-time object detection using MobileNet SSD deep learning model with a Streamlit web interface. Detects 20+ object classes in uploaded images.

**Tech Stack:** Python, OpenCV, MobileNet SSD (Caffe), Streamlit

---

### 2. [Data_Classification_AI](./Data_Classification_AI/)
Iris flower species classification using KNN algorithm. Includes data preprocessing, model training with scikit-learn, and a Streamlit app for interactive predictions.

**Tech Stack:** Python, scikit-learn, pandas, Streamlit

---

### 3. [Movie_recommendation_system](./Movie_recommendation_system/)
Content-based book recommendation system that suggests similar books based on feature similarity using cosine similarity scoring.

**Tech Stack:** Python, scikit-learn, pandas, Streamlit

---

### 4. [chat_bot](./chat_bot/)
Rule-based chatbot built with LangGraph state machines. Uses a deterministic graph-based conversation flow with sanitization, knowledge lookup, and routing nodes.

**Tech Stack:** Python, LangGraph, Streamlit

---

## 🚀 Getting Started

Each project is self-contained. To run any project:

```bash
cd <project-folder>
pip install -r requirements.txt
streamlit run app.py
```
